Python Polyseed library meant to be compatible with https://github.com/tevador/polyseed (the original C implementation),
built for ~~[Monero Signer Resurrection](https://github.com/DiosDelRayo/MoneroSigner)~~[XmrSigner](https://github.com/XmrSigner/xmrsigner), but not used anymore because Polyseed is integrated in the [OTS library](https://github.com/MoneroSDK/ots).
